# Android FCM setup

FCM code is optional until the app and server are configured. No Firebase project file or service-account credential is committed.

1. Create/select a Firebase project, register the Android package `com.kothabarta.app`, and enable Firebase Cloud Messaging. Download `google-services.json` and place it at `android/app/google-services.json`. The Gradle build applies the Google Services plugin only when this file exists; never put server credentials in this file.
2. Run the backend on Node.js 22 or newer and configure `FCM_PROJECT_ID`. For local/server deployments, provide a protected service-account key file through `GOOGLE_APPLICATION_CREDENTIALS`, or provide the JSON as the deployment secret `FCM_SERVICE_ACCOUNT_JSON`. A Google Cloud runtime identity with permission to send FCM messages can use Application Default Credentials instead. The backend uses Firebase Admin Messaging; do not commit service-account keys.
3. Build/install the Android app from a machine with the Firebase app config. On Android 13+, grant the notification permission. Sign in to register this installation's FCM token with the authenticated account; token refresh updates it, and logout attempts to remove it from that account.
4. Message pushes are data-only and contain only type, notification/message/conversation IDs, and the generic copy `Kotha-Barta` / `New message`. They never include plaintext, E2E ciphertext, attachment names, or previews. Android validates the conversation ID and loads the actual authorized conversation after a tap.

Without Firebase app config, Android token registration is disabled. Without backend FCM project credentials, push delivery is disabled. Message push attempts are deduplicated per message and installation; this deployment has no durable retry queue, so a server crash before dispatch or a failed FCM request can lose a push. FCM/Android delivery is best-effort, not guaranteed. Verify delivery, permission denial, notification taps, logout, and background/terminated behavior on a Google Play services emulator/device.
